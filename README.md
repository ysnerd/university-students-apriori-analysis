University Students’ Psychosocial, Academic and Social Indicators – Apriori Analysis
Bu depo, “Üniversite Öğrencilerinin Psikososyal, Akademik ve Sosyal Göstergeleri Arasındaki İlişkisel Örüntülerin Apriori Algoritması ile Analizi” başlıklı araştırmada kullanılan Python analiz kodlarını içermektedir.
Veri kaynağı: Rahman ve Aziz (2024), Dataset for Analyzing University Students’ Behaviour, Version 2, Mendeley Data.
DOI: https://doi.org/10.17632/5ny7cth7vw.2
Bu depoda veri ön işleme, kategorik kodlama, birliktelik kuralı analizleri ve tamamlayıcı istatistiksel değerlendirmeler için kullanılan Python kodları paylaşılmaktadır. Özgün veri seti bu depoya yüklenmemiştir; yukarıdaki kaynaktan erişilebilir.

This repository contains the Python analysis scripts used in the study “Analysis of Relational Patterns Among University Students’ Psychosocial, Academic, and Social Indicators Using the Apriori Algorithm.”
Data source: Rahman and Aziz (2024), Dataset for Analyzing University Students’ Behaviour, Version 2, Mendeley Data.
DOI: https://doi.org/10.17632/5ny7cth7vw.2
The repository provides Python scripts used for data preprocessing, categorical encoding, association rule mining, and supplementary statistical analyses. The original dataset is not included in this repository and can be accessed through the source linked above.
